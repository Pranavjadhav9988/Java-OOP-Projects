Project - Shape Metrics
In this project, you'll develop a Shape Metrics system that enables users to define and manage different types of shapes and perform essential operations such as calculating area, perimeter, and volume for applicable shapes. You’ll interact with the system through the console, allowing you to explore how various shape types behave and respond to the operations performed.

Key Concepts Applied:

Inheritance
Data Encapsulation
Aggregation(HAS-A Relationship)
Polymorphism using Method Overloading and Method Overriding
Exception handling
