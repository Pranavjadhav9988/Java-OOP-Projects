Travel Booking System

Java OOP practice project developed while learning Java on CodeChef.

Project - Travel Booking System
Let us build a Travel Booking System that allows users to create, save, and view different types of travel bookings, like Flights, Hotels, and Tours.
This project also includes persistent storage: all bookings are saved to a CSV file when created and loaded back when the application starts.
Concepts Used:

Abstract classes and methods
Inheritance
Polymorphism (using method overriding)
Super Keyword
CSV File Writing with Custom Objects
All the above concepts were covered in the OOPs concepts in Java course.
In case you need to revise these concepts, go ahead!
