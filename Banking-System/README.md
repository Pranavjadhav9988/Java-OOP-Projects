# Java OOP Banking System

A simple console-based Banking System for Java/OOP practice.

## Files
- `Account.java` - account data and deposit/withdraw operations
- `Customer.java` - customer information
- `BankingSystem.java` - manages customers
- `Logic.java` - menu and program operations
- `Main.java` - program entry point
